PUMA

Program Update Monitoring Assistant

{{ puma_version }}

Stay current. Stay secure.

PUMA checks the applications your team runs against their public release sources, and compares that against what's actually installed, so it's clear at a glance what's current and what's overdue for an upgrade.

It supports pulling release information from GitHub (releases or tags), GitLab, Atom/RSS feeds, plain HTML pages, JSON and REST APIs, HTTP response headers, and local files or Git checkouts on the server it runs on - whatever shape a given application's update source actually takes.
